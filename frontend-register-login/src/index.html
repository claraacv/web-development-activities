EXERCÍCIO DE HTML, CSS E JAVASCRIPT

Cadastro e login usando localStorage

Este projeto simula um cadastro simples de usuário e uma tela de login.

Criar conta

Preencha os dados abaixo para cadastrar um novo usuário.

O nome é inválido porque está vazio O e-mail é inválido, pois não há @ A senha é inválida pois tem menos de 6 caracteres

Entrar

Use o e-mail e a senha cadastrados para acessar o sistema.

USUÁRIO LOGADO

Esta área aparece somente depois que o login é realizado com sucesso

O que os alunos devem observar

  • O HTML deve usar elementos semântico como header , main , section , aticle e form.
  • O CSS deve organizar a tela com cards, grid, espaçamento, cores leves e estados visuais.
  • O JavaScript escuta eventos de formulário, valida dados simples e usa localStorage.
